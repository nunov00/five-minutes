# M6.3 reader-state surfaces

Status: implemented for integration review in issue #72.

## Scope

M6.3 exposes the local reader-state envelope introduced in M6.1. The later Owner-approved presentation-specific Save refinement advances it to version 2. It provides:

- Save/Unsave and Read/Unread controls on lessons;
- automatic Read and recent-reading recording when a lesson opens;
- Saved and Recent lists at the static, `noindex` `/saved` page;
- System, Light and Dark appearance preferences;
- versioned JSON export and confirmed replacement import; and
- Saved/Read markers on generated Library and Search results.

The implementation adds no account, database, server endpoint, analytics or tracking. State remains in `five-minutes.reader-state` in browser storage and every mutation goes through `src/lib/reader/state.ts`. Read state is keyed by immutable lesson ID. Saved and Recent entries retain their exact edition and are keyed by ID plus edition; Recent is ordered newest first and capped at 50.

## Personal page

`/saved` loads the existing compact browser catalogue only to join stored IDs to current titles and URLs. Saved entries link only to the exact presentation saved; recent entries reopen the edition visited. Titles and dates are shown without redundant Adult/Teen prefixes. An ID absent from the current catalogue is retained in storage and reported rather than discarded. The page is excluded from search indexing and the sitemap.

The global Saved navigation label is present on every page. On `/saved`, the Adult/Teen selector controls the normal publication preference without changing the personal-page URL.

## Appearance

Appearance is `system`, `light` or `dark`. A small guarded head read applies a valid stored value before rendering; all writes still use the storage abstraction. Explicit Light and Dark override the operating-system scheme. Failure to read storage leaves the system theme and all content usable.

## Export and import

Export downloads a version 2 JSON document, formatted for readability when it fits the 1,000,000 UTF-16-code-unit reader-state limit and compact otherwise. Export never adds whitespace beyond that limit. The file-size preflight permits up to 3,000,000 UTF-8 bytes so non-ASCII backups within the character bound remain importable; decoded data must still pass the original character limit and complete schema validation. Import:

- accepts at most 1,000,000 characters;
- requires the reader to select a file and confirm replacement;
- applies the same version and field validator used for stored state while preserving additive unknown fields;
- accepts version 2 and valid version 1 data that can be deterministically migrated; and
- never overwrites current, corrupt or future-version data when validation or writing fails.

A confirmed import replaces the complete version 2 envelope, including the saved edition preference. Valid version 1 identity-only Saved entries migrate to the saved preference, or Adult when none exists, while other fields and additive extensions are retained. This is an explicit data-restoration action rather than an implicit edition change caused by opening a shared URL; outside import, the ADR-0009 selector rules remain unchanged.

There is no pre-M6 migration: no genuine earlier reader-state format was published.

## Failure and accessibility behaviour

Without JavaScript, lessons, Recall, edition links and discovery remain usable, while the personal features explain that JavaScript is required. Blocked, full, corrupt or future-version storage keeps the M6.1 preservation and explicit-reset behaviour. Storage events and page restoration refresh visible state. Controls use native buttons, radios, checkbox and file input; statuses are live regions.

Automated coverage includes the storage contract, bounded recent history, immutable-ID semantics, appearance, invalid/future imports, Saved/Recent rendering, Library markers, no-JavaScript behaviour and mobile/desktop Chromium journeys. Real Safari Back/bfcache, installed-app launch, iPhone text scaling and screen readers remain the M6.4 integration gate.
